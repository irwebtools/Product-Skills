# From product idea to working POC

Product roles explain the need. AI uses `product-skills`. Development Team continues production work.

```text
Idea -> Brief -> Stories -> Acceptance -> Journey -> UX -> React FSD POC -> Validation -> Handoff
```

## Skills used

1. `product/project-analysis` when the workspace is unknown or existing
2. `product/product-discovery`
3. `product/product-definition`
4. `product/user-story`
5. `product/acceptance-criteria`
6. `product/ux-flow`
7. `delivery/architecture-decision`
8. `delivery/react-fsd-poc`
9. `quality/verification`
10. `quality/security-review` when needed
11. `product/validation`
12. `delivery/developer-handoff` after acceptance

Human review artifacts live under `.ai-review/`.

## Product loop

1. Provide problem / users / goal
2. Confirm definition, stories, acceptance, and journey
3. Try the POC
4. Validate against acceptance criteria
5. Accept behavior before developer handoff

PREVIEW_READY means ready for Product feedback.
DEV_READY means ready for Development Team continuation.
Neither is production approval.
