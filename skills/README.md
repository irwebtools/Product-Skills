# Skills

`skills/` is the canonical Product-Skills capability library.

The library is intentionally small. A concept becomes a separate skill only when it has independent reuse value.

## Core skills

1. `definition`
2. `ux-ui`
3. `react`
4. `supabase` — conditional
5. `verify`
6. `delivery`

A normal task should load only the skills it actually needs.
